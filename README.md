# HuntersAlgo documentation

This repo is a plain-text mirror of the public documentation for HuntersAlgo. It holds the setup guide, the FAQ and the changelog, so you can read them on GitHub without opening the site.

HuntersAlgo is a suite of automated futures trading strategies built for NinjaTrader 8 and TradingView. Most strategies are built for NQ, ES, GC or SI, and several run on any liquid futures contract. The subscription also includes HunterStrike, an intraday levels indicator for NinjaTrader 8.

This repo is documentation only. The strategies and indicators are delivered through the subscriber download, not through GitHub.

## Start here

2. [FAQ](docs/faq.md): strategies, licensing, trading and technical questions.
3. [Changelog](CHANGELOG.md): every shipped change, dated, with the reason.

## Where to get help

- **Discord (fastest):** <https://huntersalgo.com/discord>. It is active during US trading hours, and subscribers and I answer most setup questions within minutes.
- **Email (slower):** <https://huntersalgo.com/contact>. Use it for licensing or billing issues that need a paper trail. Replies take 1 to 2 business days.
